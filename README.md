# Aryan Mishra — Professional Data Analyst Portfolio

A responsive Next.js portfolio inspired by the supplied green-and-ivory reference. Includes project case-study modals, searchable/filterable projects, skills, education, original certificate previews and PDF links, resume preview/download, contact links, mobile navigation and light/dark theme.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
```

The project is configured for static export (`out/`) and can be deployed on Vercel. Import the GitHub repository and use the default Next.js build settings. No environment variables are required.
